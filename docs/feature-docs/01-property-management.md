# Property Management

## What is it

The Property Management feature is the landlord's central inventory workspace in the Rental Management Platform. It gives a single view of all rental units (for example dorms, condos, apartments, and Airbnb units) so landlords can quickly see what they own, what is occupied, and what is available.

For each property/unit, the feature stores core operational details:
- Property type
- Address/location
- Monthly rent amount
- Occupancy status
- Unit notes

In this POC phase, the feature is UI-first and powered by mock data. The goal is to help landlords manage multiple properties from one page without relying on scattered spreadsheets, chat threads, or paper notes.

## Why it matters

- Creates one source of truth for all rental inventory
- Speeds up day-to-day tracking of occupied vs vacant units
- Reduces manual admin overhead before billing and tenant follow-up steps
- Acts as the foundation for tenant assignment, reminders, and invoicing flows

## POC Scope

**In scope now**
- Property list view
- Property detail view
- Add/edit property information in mock flow
- Visible occupancy and rent information per unit

**Out of scope for now**
- Live backend sync
- Automated occupancy updates from payments
- Multi-user access controls
